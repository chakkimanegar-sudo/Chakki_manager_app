# Chakki Manager — Bug Fix Audit

## Fixed in this build

1. **Multi-device delete resurrection**
   - Client now sends its last known server snapshot as `base` on every PUT sync.
   - Server performs a three-way merge so a real client deletion is not treated as missing data that should be restored.
   - Older clients that do not send `base` are blocked from overwriting a non-empty shop.

2. **Unsynced local changes being overwritten by pull**
   - A periodic pull no longer blindly replaces local data when this device has changes that have not reached the server.
   - Those changes are pushed through the three-way merge first.

3. **Concurrent sync race**
   - Server write is protected by a database transaction and row lock.
   - This prevents two phones from reading the same old snapshot and then overwriting each other's merge.

4. **Billing ↔ Khata consistency**
   - Deleting a billing record also removes every Khata transaction linked to that record.
   - A billing-linked transaction cannot be independently deleted from Khata, because reconciliation would otherwise recreate it.
   - Editing an Udhar bill to a different customer moves the linked Khata transaction to the new customer.
   - Server removes orphan transactions and collapses duplicate transactions linked to the same billing record.

5. **Customer history safety**
   - A customer with transaction history can no longer be deleted accidentally, which previously could destroy accounting history.

6. **Stale React state on Records**
   - Add/update/delete operations now read the latest localStorage state before mutating, preventing stale-closure overwrites after sync or rapid edits.

7. **Rate sync**
   - Rate changes now dispatch the same storage event used by the sync system, so they participate in automatic multi-device sync.

8. **Backup restore sync**
   - Restored data now dispatches storage events, so the sync system detects the restored records/settings instead of silently leaving the server unchanged.

9. **PWA cache refresh**
   - Service-worker cache version bumped from `chakki-v3` to `chakki-v4` so an old cached app is less likely to hide the fixed build.

10. **PWA icons**
    - Added the missing 192px and 512px web icons using the existing app icon.
